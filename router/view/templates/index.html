Browser Import
Recommended for quick updates: paste a fresh Firefox Copy as cURL request for chatvideocontext or biocontext, then save. The app will extract the cookie jar and User-Agent automatically, and it skips room-specific tbu_* cookies.
Cookies
Paste the full cookie string from your browser when values rotate. Raw Cookie: lines are accepted and persisted in conf/settings.json. If you paste only cf_clearance=..., the app updates that cookie while keeping the rest of the stored cookie jar. Room-specific tbu_* cookies are dropped automatically. See README for details.

Off for every channel until you turn it on in its own settings (gear button). The detector is a small separate program (folder detector, see docs/GUIA_DETECCION.md).
